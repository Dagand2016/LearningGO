# Git шпаргалка

Короткая и удобная памятка по самым нужным командам Git.

## Основные команды

| Команда | Что делает |
|---|---|
| `git init` | Создает новый Git-репозиторий |
| `git clone <url>` | Копирует удаленный репозиторий на компьютер |
| `git status` | Показывает состояние файлов и ветки |
| `git add <file>` | Добавляет файл в подготовку к коммиту |
| `git add .` | Добавляет все изменения в текущей папке |
| `git commit -m "msg"` | Сохраняет изменения в историю |
| `git log` | Показывает историю коммитов |
| `git log --oneline` | Показывает короткую историю коммитов |
| `git diff` | Показывает текущие изменения |
| `git diff --staged` | Показывает изменения, добавленные в `git add` |
| `git branch` | Показывает список веток |
| `git branch <name>` | Создает новую ветку |
| `git switch <name>` | Переключается на ветку |
| `git switch -c <name>` | Создает ветку и сразу переключается |
| `git merge <name>` | Вливает указанную ветку в текущую |
| `git fetch` | Скачивает изменения с сервера без слияния |
| `git pull` | Скачивает изменения и сразу применяет |
| `git push` | Отправляет коммиты на сервер |
| `git remote -v` | Показывает подключенные удаленные репозитории |
| `git stash` | Временно прячет изменения |
| `git stash pop` | Возвращает спрятанные изменения |
| `git restore <file>` | Отменяет изменения в файле |
| `git restore --staged <file>` | Убирает файл из индекса |
| `git rm <file>` | Удаляет файл из Git и папки |
| `git mv <old> <new>` | Переименовывает или перемещает файл |

## Самый нужный минимум для новичка

| Ситуация | Команда |
|---|---|
| Проверить, что происходит | `git status` |
| Добавить изменения | `git add .` |
| Сохранить изменения | `git commit -m "описание"` |
| Отправить на GitHub | `git push` |
| Забрать изменения | `git pull` |
| Посмотреть историю | `git log --oneline` |
| Создать новую ветку | `git switch -c new-branch` |

## Простой рабочий порядок

```bash
git status
git add .
git commit -m "описание изменений"
git push
```

## Полезно помнить

- `git add` подготавливает изменения к сохранению.
- `git commit` сохраняет изменения в историю.
- `git push` отправляет ваши коммиты в удаленный репозиторий.
- `git pull` забирает изменения из удаленного репозитория.
- `git branch` и `git switch` помогают работать с ветками.
